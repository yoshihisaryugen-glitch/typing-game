# TYPING GAME

ブラウザで動くタイピングゲームです。Docker 上の nginx で配信します。

## 起動

```bash
docker compose up --build
```

ブラウザで http://localhost:8080 を開きます。

止めるときは `Ctrl+C` のあと、次を実行します。

```bash
docker compose down
```

## 遊び方

スタート画面には「スタート」と「設定」があります。

- **スタート**: タイピングを開始します。表示された文字列をそのまま入力すると、次の問題に進みます。
- **設定**: 次の 5 種類がどれくらい出るかを、0 から 5 で決めます。0 にすると、その種類は出ません。
  - Pythonの単語と記号
  - 記号
  - 日本語の単語
  - 英語の単語
  - 数字（0〜9の5桁）
  - カスタム（設定画面のテキスト。1行が1問。頻度をすべて0にしても、ここに文字があれば出題されます）

数字が大きいほど、その種類が多く出ます。たとえば Python が 5 でほかが 1 のとき、Python はほかの 5 倍の割合で出ます。設定はこのブラウザに保存されます。

ゲーム中の「終了」で結果を表示します。結果の「苦手な文字にフォーカス」では、その回に間違えた文字と、入力に時間がかかった文字を中心に出題します。
